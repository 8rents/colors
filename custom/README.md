![Neon Dark Theme](screenshot.jpg)

## Usage

Simply symlink the `neon.properties` file into the `.termux` folder as `colors.properties`. 

Like so (assuming you've copied or symlinked it into the favorites folder):

```bash
ln -s ~/dev/colors/favorites/neon.properties ~/.termux/colors.properties'
```

## Files

- `neon.properties` - Termux Color File
- `swatches.aco` - Photoshop Swatches File

## Good terminal color scheme designer tools

I so far have had good luck starting with root loops and then finishing schemes in terminal.sexy. V2 was designed this way. 

- [rootloops.sh](https://rootloops.sh) - Good starting point for basic color combinations as it works with a HSL based color coordination scheme.
- [terminal.sexy](https://terminal.sexy) - Good for refining existing schemes

### If using one of the above

Export in: 

- `termite` format 
- `kitty` is the next closest
