## Usage

Simply symlink the `color.properties` file into the `.termux` folder as `colors.properties`. 

```bash
ln -s ~/dev/colors/favorites/color-scheme-name.properties ~/.termux/colors.properties'
```

## Files

- `color-scheme-name.properties` - Termux Color File
- `swatches.aco` - Photoshop Swatches File
