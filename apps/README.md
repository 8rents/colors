# App Color Schemes

> *This folder holds color schemes taylored for specific apps*

---

## Development

1. New color schemes are produced in the `app/dev` folder. 
2. When they are finished they are moved to the `app/complete` folder.
3. A new branch is created called "name of  app" and the completed folder is  merged onto the branch root.

## Usage

Appdata is cloned by branch and incorporated into app settings.
